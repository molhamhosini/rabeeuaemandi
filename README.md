# ربيع الإمارات للمندي

الموقع والتطبيق الجديد لمطعم ومطبخ ربيع الإمارات للمندي (أبوظبي: فرع الدانة وفرع الشهامة الجديدة).

| المجلد | المحتوى |
|---|---|
| `website/` | موقع Laravel عربي/إنجليزي، لوحة تحكم `/admin`، واجهة API للتطبيق، طلب عبر واتساب ودفع عبر Stripe. خطوات الرفع على Hostinger في `website/DEPLOY.md` |
| `app/` | تطبيق Flutter (أندرويد وآيفون) يقرأ القائمة ويرسل الطلبات لنفس الخادم. التعليمات في `app/README.md` |

صور الأطباق مأخوذة من ملفات المنيو المطبوع (PSD) وموحّدة على خلفية واحدة في `website/public/images/menu/`.
